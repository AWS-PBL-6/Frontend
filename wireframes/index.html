  • 의존성: Google IdP는 Google Cloud OAuth 클라이언트(ID/시크릿) 필요 — 사용자 준비.

  • Ack → POST /v1/events/{id}/ack (낙관적 업데이트).

제안 기술 스택

  • React + Vite + TypeScript, React Router, TanStack Query(REST) + 커스텀 WebSocket 훅.
  • AWS Amplify Auth (Cognito) — 이메일/비번(SRP) + Google 페더레이션(OAuth2 리다이렉트).
  • three.js + @react-three/fiber + drei — 이벤트 상세 홋줄 3D (지연 로딩).
  • 디자인 토큰 CSS — 위 통일 팔레트를 CSS 변수로, Inter 폰트. 무거운 UI 킷 미사용.
  • 지도 — SVG 자체 구현.

확인 부탁드리는 결정 사항

1. 통일 팔레트

무채 웜그레이 지배 + 어시 상태색(세이지/오크/테라코타) + 단일 액센트(#0b5cad, design.md 블루를 살짝 낮춤)로 정돈했습니다. 이 방향 OK? (더 단색화: “위험만 유채색, 정상/주의는 무채+아이콘” 대안도 가능)

2. 이벤트 상세 three.js 홋줄 3D

상태별 마모·파단·진동·스냅백 방향을 실시간 3D로 표현. 지연 로딩으로 성능 관리. 이 스코프로 진행 OK? (초기엔 단순 형상→점진 고도화 제안)

3. 로그인 = 이메일/비번 + Google

요청대로 반영. Google 연동을 위해 Google Cloud OAuth 2.0 클라이언트(ID/시크릿) 발급이 필요합니다 — 준비 가능하신가요? 준비 전까지는 이메일/비번만 활성화하고 Google 버튼은 비활성 자리표시로 둘 수 있습니다.

4. 화면 범위 · 지도

로그인·대시보드·이벤트 상세·이력 4개. 안벽 지도는 도식 SVG(백엔드 layout 좌표), 실제 도면 이미지 있으면 배경으로. 이대로 OK?

확인해 주시면: 백엔드 SAM에 Cognito(User Pool + App Client + Hosted UI 도메인 + Google IdP + JWT authorizer) 추가 → React 스캐폴딩 → 인증 → 대시보드 → 이벤트 상세(3D) 순으로 구현합니다.
